# Chatlytics – WhatsApp Chat Analysis Tool

A full-stack **data analytics + network analysis tool** built using Python and Streamlit to extract meaningful insights from WhatsApp chat exports.

---

## Features

### Chat Statistics
- Total messages, words, media, and links  
- Average words per message  
- User-wise analysis  

### Text Analysis
- Word cloud generation  
- Most common words  
- Stopword filtering (Hinglish supported)  

### Time-based Insights
- Monthly and daily timelines  
- Most active day and month  
- Weekly activity heatmap  

### Emoji Analysis
- Most frequently used emojis  
- Emoji usage patterns  

### Advanced Network Analysis
- Interaction graph between users  
- Community detection  
- PageRank-based influence ranking  
- Top connectors and low-interaction users  

**Custom Filters:**
- Date range  
- Interaction strength  
- Reply time window  
- Node limits  

---

## Tech Stack

- **Frontend**: Streamlit  
- **Backend**: Python  

**Libraries Used:**
- Pandas, NumPy  
- Matplotlib, Seaborn  
- WordCloud  
- NetworkX, Plotly  
- Scikit-learn (LDA Topic Modeling)  
- VADER Sentiment Analysis
